JLC Part Catalogue Import

Upload a DipTrace CSV/XLSX file. Preview checks every JLCPCB C-code against the spreadsheet manufacturer number and existing InvenTree records. Mismatches need explicit review. Nothing is saved until you apply the reviewed import.

Review

For each new Part, choose or create a category. When MPNs differ, search for the spreadsheet MPN's manufacturer or type a new name, then confirm interchangeability. If an existing company is not marked as a manufacturer, explicitly approve that role change. The JLCPCB supplier SKU links to the JLCPCB manufacturer MPN.

JLC Part Catalogue Import

Upload a DipTrace CSV/XLSX file. The original Footprint stays unchanged; edit the spreadsheet MPN for any row that includes a CAD prefix, then Check again before saving. Mismatches need explicit review.

Review

For each new Part, choose or create a category. The editable spreadsheet MPN is checked separately from the original DipTrace Footprint. When MPNs differ, choose their manufacturer—even if it is the same as the JLC manufacturer—and confirm interchangeability. The JLCPCB link is saved automatically; an optional spreadsheet MPN link can be added. Unsaved edits stay in this browser for this file; reselect and preview the same file after a refresh to restore them.
